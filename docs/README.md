# XMage Documentation

This directory contains technical documentation for the XMage project.

## Documentation Files

### [Python Gymnasium Client Architecture](PYTHON_CLIENT_ARCHITECTURE.md)

Comprehensive documentation for building a Python client designed as a Gymnasium environment to interface with the XMage server.

**Contents:**
- Architecture overview with component diagrams
- Connection and authentication specifications
- Communication protocol details (JBoss Remoting, Java serialization)
- Message structures and data models
- Action space definitions for reinforcement learning
- Observation space specifications
- Full Gymnasium environment implementation
- Working code examples
- Complete API reference
- Implementation notes and recommendations

This documentation is designed for developers who want to:
- Build AI agents that play Magic: The Gathering
- Create reinforcement learning environments for card games
- Interface with the XMage server programmatically
- Understand the XMage client-server protocol
